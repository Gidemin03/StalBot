# Игровые правила Stalzone — контекст для StalBot

Этот документ описывает особенности игры Stalzone и её аукциона, которые необходимо учитывать при разработке StalBot.

Информация основана на наблюдениях и описании пользователя. Это не документация API игры.

**Важно:** здесь описываются игровые механики, а не способы их программной реализации. Текущая реализация описана в `ARCHITECTURE.md`, распознавание — в `OCR.md`.

## 1. Общие особенности интерфейса

- Бот разрабатывается для игрового интерфейса при разрешении **1920×1080**.
- Во время обычного анализа аукциона строки лотов сохраняют свои положения.
- В списке аукциона одновременно отображается до **10 лотов**.
- Каждый лот имеет собственную строку с названием, изображением предмета, количеством и ценами.
- При выборе лота под ним появляется меню действий с возможностью выкупа.
- Для десятого лота меню покупки оказывается ниже видимой области. Для доступа к нему требуется прокрутка.
- После успешной покупки или обнаружения уже выкупленного лота список аукциона обновляется. Старый скриншот больше нельзя считать актуальным.
- По сообщению пользователя от 2026-10-15 выкупленный лот иногда исчезает с задержкой:
  после Search ещё видна старая строка, а обновление приходит уже при попытке открыть
  её меню. Видимость старого лота не подтверждает, что он всё ещё доступен.

Точные координаты интерфейса и ROI относятся к технической реализации и хранятся в документации Dataset Builder / OCR.

## 2. Название предмета

- Названия предметов отображаются кириллицей.
- Название может содержать буквы, цифры и специальные символы.
- У длинных названий, которые не помещаются в строку аукциона, конец заменяется на `..`.
- Сокращённая видимая подпись не всегда позволяет однозначно определить полное название предмета.
- Цвет текста имени является визуальным признаком редкости.

## 3. Редкость предметов

Существует шесть цветовых уровней редкости.

Для артефактов:

1. Обычный
2. Необычный
3. Особый
4. Редкий
5. Исключительный
6. Легендарный

Для других предметов:

1. Отмычка
2. Новичок
3. Сталкер
4. Ветеран
5. Мастер
6. Легенда

Соответствие уровней:

| Артефакт | Другой предмет |
|---|---|
| Обычный | Отмычка |
| Необычный | Новичок |
| Особый | Сталкер |
| Редкий | Ветеран |
| Исключительный | Мастер |
| Легендарный | Легенда |

Соответствующие уровни обозначаются одинаковыми цветами.

**Важная особенность:** редкость влияет на экономическую ценность не каждого предмета. Для некоторых предметов различие по цвету существенно, для других — нет.

Не следует автоматически считать, что всем предметам требуется отдельная закупочная цена для каждого цвета.

## 4. Заточка

Некоторые предметы могут иметь уровень заточки.

Основные категории, где встречается заточка:

- артефакты;
- огнестрельное оружие;
- броня.

По наблюдениям пользователя, чаще всего заточка встречается у артефактов.

Формат отображения:

`Название | +N`

Примеры:

- `Вихрь | +1`
- `Вихрь | +12`
- `Вихрь | +15`

Особенности:

- Максимальный уровень заточки — **+15**.
- Заточка отображается через последовательность ` | +`.
- Уровни заточки могут существенно влиять на стоимость.
- Если у предмета, для которого применима заточка, на полном видимом названии отсутствует обозначение `| +N`, это соответствует отсутствию заточки (+0).
- По прямому уточнению пользователя от 2026-10-15, при сокращённом имени заточка
  всегда +0. Это игровое правило; прежняя оговорка о неизвестной заточке для
  сокращённого имени снята.
- Если у несокращённого имени часть суффикса заточки не читается, считать её +0 нельзя.
- Для предметов, к которым заточка неприменима, не нужно придумывать игровой уровень заточки.

## 5. Количество предметов

- Один лот может содержать несколько одинаковых предметов.
- Количество отображается цифрами поверх иконки предмета.
- Если число количества **действительно отсутствует**, это означает **1 предмет**.
- Стоимость выкупа относится ко **всему лоту**, а не к одной штуке.

Пример:

Количество: 4

Цена выкупа: 100 000 рублей

Цена выкупа за штуку: 25 000 рублей.

Важно отличать подтверждённое отсутствие числа от ситуации, когда число не получилось распознать.

Это особенно существенно для расчёта выгоды: ошибка в большую сторону может привести к покупке убыточного лота.

## 6. Цены и валюта

- Валюта аукциона — **рубли**.
- Цены отображаются целыми числами.
- Разряды числа разделяются пробелами.

Примеры:

- `101`
- `59 000`
- `5 251 000`
- `59 000 300`
- `1 000 000 000`

По предоставленной информации, возможная стоимость находится в диапазоне от **1 до 9 999 999 999 рублей**.

Если цена отсутствует, в интерфейсе отображается:

`---`

### 6.1 Цена ставки и цена выкупа

В аукционе есть две разные цены:

- BID — цена ставки;
- BUYOUT — цена немедленного выкупа.

Для основного сценария StalBot используется именно **BUYOUT**.

При больших значениях цифры BID и BUYOUT могут визуально сближаться или перекрываться.

Это особенность интерфейса, которую важно учитывать при распознавании.

Если полную цену BUYOUT невозможно надёжно отделить от других цифр, делать вывод о стоимости лота нельзя.

### 6.2 Комиссия

При продаже предмета через аукцион удерживается комиссия **5%**.

Соответственно, продавец получает 95% от цены продажи.

Это нужно учитывать при расчёте предполагаемой прибыли от перепродажи.

## 7. Покупка на аукционе

При выборе лота под соответствующей строкой появляется меню действий.

В нём находится кнопка выкупа.

После попытки покупки возможны следующие известные игровые результаты:

**Успешная покупка**

Предмет приобретён.

**Лот уже выкуплен**

Другой игрок успел купить предмет раньше.

По наблюдению пользователя от 2026-10-19 при такой неуспешной попытке баланс
может временно уменьшиться примерно на полсекунды, затем появляется уведомление
о недоступности лота и средства возвращаются. Это примерная задержка, а не
гарантированный сервером срок. Первое видимое списание само по себе не подтверждает покупку.

**Недостаточно средств**

На игровом балансе не хватает рублей для покупки.

Дополнительные неизвестные окна, ошибки взаимодействия и отсутствие распознанного уведомления должны рассматриваться программой отдельно. Это не подтверждённые игровые статусы.

Примеры экранов находятся в `dataset/templates/`.

## 8. Поиск и обновление списка

В аукционе есть кнопка Search, обновляющая список лотов.

По наблюдениям пользователя:

- Обновление происходит не мгновенно.
- Задержка может быть небольшой, ориентировочно около 100 мс.
- После изменения списка прежний скриншот нельзя использовать для следующих покупок.
- Search может вернуть визуально прежний список: отсутствие новых лотов нормально.
  Неизменность пикселей сама по себе не подтверждает ответ сервера.

**Около 100 мс — предварительная оценка, а не гарантированное время ответа интерфейса.**

## 9. Сортировка лотов

По описанию пользователя:

- Аукцион сортируется по времени окончания лотов.
- Максимальное время существования лота — 48 часов.

По уточнению пользователя от 2026-10-15 новые предложения обычно появляются
сверху вниз; изредка из-за задержек игры — на второй или третьей строке.
Это наблюдение пользователя, а не доказательство, что контроль первых четырёх
строк обнаружит любое обновление. Статические скриншоты не доказывают порядок
появления строк; для этого нужна последовательность кадров живого обновления.

## 10. Что не является игровым правилом

Следующие положения — решения реализации StalBot, а не механики игры:

- Анализ только первых девяти строк в FreshLotsStrategy.
- Использование OCR для NAME, QTY и BUYOUT.
- Максимальная цена покупки, установленная пользователем.
- Закупочные правила и цены из каталога.
- Обработка неоднозначного OCR.
- Выбор batch 1/3/9.
- Повторные проверки перед BUY.
- Способы хранения данных и история сделок.
- Механизм паузы, остановки и восстановления.

Их актуальное поведение нужно смотреть в документации реализации и исходном коде.
