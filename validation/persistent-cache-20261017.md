# Сохраняемый NAME LRU и время сессии — 2026-10-17

Реализация: `stalbot/cache_storage.py`, `name_cache.py`, `reader_factory.py`,
`session_clock.py`; интеграция UI, Runner и CLI. CPU/GPU используют отдельные
файлы `data/name-cache/cpu.names` и `dml.names`. Записи содержат только исходный
RGB NAME и Identity, порядок LRU сохраняется. Цены, количество и решения не сохраняются.

Формат имеет версию, fingerprint модели/обработки/runtime и SHA-256. Файл целиком
проверяется перед принятием записей; несовместимость или повреждение дают пустой кеш.
При загрузке соблюдается выбранная ёмкость. Нулевой лимит сохраняет прежний файл,
но отключает загрузку и запись. Один writer атомарно заменяет файл; автосохранение
изменений примерно раз в минуту, в том числе при паузе, плюс ожидание записи при
завершении задания/закрытии. Неудачная запись не заменяет прежний файл.

Время сессии измеряется монотонными часами от Start/Replay до завершения задания,
включает подготовку, паузы и завершение. После остановки значение остаётся на экране,
новый запуск сбрасывает его. CLI выводит `session_seconds`.

## Ограничения

Реальный игровой ввод и покупки не запускались. Автосохранение выполняется в ближайшей
безопасной точке; аварийное завершение может потерять последние несохранённые изменения.
Несколько процессов не объединяют кеши: сохраняется последний записанный снимок.
Совместимость намеренно консервативна: обновление модели, обработки или runtime может
потребовать накопить кеш заново. Старый RAM-кеш уже работающей версии перенести нельзя;
постоянное сохранение начинается после перезапуска на обновлённой версии.
Все native-проверки использовали отдельные каталоги validation и временные БД.
