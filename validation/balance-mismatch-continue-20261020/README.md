# Расхождение баланса без остановки — 2026-10-20

По запросу пользователя завершённый BALANCE_MISMATCH больше не останавливает
Runner и не блокирует Store.unresolved/begin_buy, включая старые записи после
перезапуска. Рабочая SQLite не редактировалась: миграция статусов не требуется.

Фактический баланс по-прежнему сохраняется атомарно при сверке. Ожидаемое и
фактическое списание, исходный статус и итог BALANCE_MISMATCH сохраняются в
attempt.balance_check, событии SQLite balance_check и диагностике покупки.
Исключение больше не создаётся, поэтому запись traceback в errors.log не требуется.
Попытка не становится SUCCESS и не добавляет прогноз прибыли. В истории
расхождение остаётся доступным для аудита.

Незавершённая сверка balance_pending, непрочитанный/нестабильный баланс,
BUY_SENT, UNKNOWN, INSUFFICIENT и порог бюджета сохраняют прежнюю семантику.
После UNKNOWN сохраняется требование нового Search; повторного BUY в той же
попытке нет. При прочитанном остатке ниже 50 000 ₽ действует прежний бюджетный стоп.

Обновлены runner.py, storage.py, пояснение UI, README, ARCHITECTURE,
TESTING и DEVELOPMENT_PLAN. Тесты проверяют расходы больше/меньше ожидаемого,
рост счёта, сохранность журнала, следующий Search, новую попытку после
перезапуска и исходы SUCCESS/UNAVAILABLE/UNKNOWN.

Проверка: **342 unit/Tk-теста PASS**, 35,346 с, код завершения 0.
[Лог](tests.log). Fake desktop/WinAPI, временные БД; реальный ввод в игру
не выполнялся. OCR не менялся, полный OCR-прогон повторно не запускался.
