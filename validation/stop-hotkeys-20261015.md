## Изменение

`stalbot/hotkeys.py` регистрирует F8/F9 с `MOD_NOREPEAT` в отдельном потоке,
читает `WM_HOTKEY` и передаёт события в очередь Tk. Регистрация обязательна
до запуска рабочего потока; при частичном отказе уже занятые клавиши освобождаются.
Завершение запуска освобождает регистрации. Ошибка сборщика запрашивает стоп.

`Runner.purchase()` повторно проверяет отмену после захвата/распознавания
уведомления, непосредственно перед OK. Эта проверка не делает распознавание,
проверку отмены и Windows-ввод одной атомарной операцией.

Семантика Windows API сверена с
[RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey).
