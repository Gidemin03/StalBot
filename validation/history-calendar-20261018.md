## Результат

- Вместо ручного ввода дат — календарь Tk с русскими месяцами и неделей с понедельника,
  переходом по месяцам, выбором дня, сбросом и отменой. Дополнительных пакетов нет.
- «Вчера», «Сегодня», «Все даты» задают период одним нажатием. Даты применяются
  сразу, остальные фильтры сохраняются. При пересечении границ календаря другая
  граница сдвигается на выбранный день.
- История и даты фильтров используют местный часовой пояс Windows; исходные UTC
  timestamps в SQLite не меняются. Обе границы дня включены, в том числе микросекунды
  непосредственно перед полуночью. Для точного перевода используется datetime,
  поскольку SQLite date() округляет 23:59:59.999999 до следующего дня.
- Store.history по умолчанию возвращает все доступные записи. Явный limit остаётся
  необязательным аргументом API; UI не задаёт его. Над таблицей отображается фактическое
  число записей без надписи об ограничении в 200.
- Сумма прогноза и число покупок считаются по SUCCESS среди всех записей,
  прошедших текущие фильтры. Без фильтров это вся неочищенная история; «Вчера» даёт
  прогноз за вчерашний местный день. Decimal сохраняет точность копеек, комиссия 5%
  уже входит в сохранённый profit и повторно не вычитается. UNKNOWN, резерв,
  MANUALLY_REVIEWED и прочие неуспешные попытки прибыль не добавляют.
- Очистка исключает скрытые записи из суммы, сохраняя бюджет, прибыль сессии
  и защиту повторного BUY. QTY AMBIGUOUS остаётся расчётом по 1, а не подтверждённым количеством.
